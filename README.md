## Description

**Irc** is a protocol to communicate between 2 clients
The **ft_irc** project consist in creating an IRC server respecting the irc RFC (RFC 2812)

## Instructions

### Compilation
```bash
make
```

### Usage
```bash
./ircserv <port> <password>
```
